# Nigeria spread simulations

This directory holds the stochastic spread simulations for the five Nigerian
states, one file per state:

    df_sims<state>.joblib        e.g. df_simsanambra.joblib

**These files are not in the repository.** The five states are whole
administrative units rather than 50 km by 50 km sub-landscapes, so each set of
2,000 simulations is far larger than the equivalent file for the main analysis,
and the five together exceed what can reasonably be hosted here.

The `kernels/` subdirectory is where `run_sims_nigeria.py` writes the precomputed
dispersal kernel for each state. These are not committed either, for the same
reason, and are regenerated by the same script.

## Regenerating them

    python main_analysis/code/nigeria_comparison/code/run_sims_nigeria.py <State>

The state argument is capitalised to match the host distribution filenames, for
example `Anambra`, and the host distributions must first be converted from
shapefile to `.joblib` as described in `../../host_distributions/README.md`.
Re-running regenerates the simulations, but the draws will differ from those the
published results were computed from unless the seeds are reproduced exactly.

## What is in the repository

The optimisation results computed from these simulations are committed, under
`../output_metric/`, `../output_config/` and `../output_trace/`, so every
Nigerian figure and reported value can be reproduced without re-running the
simulations.
