# Within-cell variation test

`noise_test_scores.csv` holds one row per study area, giving the objective
and the optimal objective proportion of each stored optimum under three
levels of within-cell variation in disease progression, none, 0.25 and
0.5, together with the number of single-swap neighbours that outperformed
it at each level.

Read by `figureS8.py`, which plots the objectives and proportions with
variation against those without.

## Noisy simulations

`score_noise_test.py` also expects `simulations/` here, holding
`df_sims{AREA}_noise{LEVEL}.joblib` for each sub-landscape at noise levels
0.0, 0.25 and 0.5. Those 24 files are not committed, since each is of the
same order as the main simulation files.

They are deposited at <https://doi.org/10.5281/zenodo.23214313>, as `noise_test_simulations.7z`. Extract that
archive into this directory to recreate `simulations/`. They can also be
regenerated by step 1 of the test, although the draws will differ unless the
seeds are reproduced exactly.

The scored results computed from them are committed here as
`noise_test_scores.csv`, so Figure S8 and Supplementary Note 3 can be
reproduced without the simulations themselves.
