# Within-cell variation test

`noise_test_scores.csv` holds one row per study area, giving the objective
and the optimal objective proportion of each stored optimum under three
levels of within-cell variation in disease progression, none, 0.25 and
0.5, together with the number of single-swap neighbours that outperformed
it at each level.

Read by `figureS8.py`, which plots the objectives and proportions with
variation against those without.
