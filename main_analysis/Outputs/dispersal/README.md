# Dispersal distances

`dispersal_distances.joblib` holds the distances of every simulated
dispersal event, keyed by sub-landscape. Pooled across the eight, it
contains 258,385 events spanning 1.0 to 58.7 km.

Read by `figure3.py`, which fits a truncated power law to the pooled
distances for Figure 3 and plots the per-sub-landscape distributions for
Figure S6.
